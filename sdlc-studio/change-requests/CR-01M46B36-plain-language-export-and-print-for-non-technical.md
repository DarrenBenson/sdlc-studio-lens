## Summary

A project manager needs the views to explain themselves: a glossary and tooltips in plain language (for example 'points: the agreed size of a piece of work, not hours'), an 'as of' freshness stamp on every figure, a print stylesheet for the sprint report and portfolio, and CSV export of the sprint, cost and quality tables. Refresh the brand guide (Draft) to cover these states and approve it. Depends on: CR-01M46B9P, CR-01M46BFX, CR-01M46BPJ, CR-01M46B04, CR-01M46BT9, CR-01M46BC2.

## Impact

Without it the observability plane is only usable by people who already know sdlc-studio.

## Acceptance Criteria

- [ ] Every metric label on the sprint, cost, DORA and quality pages has a glossary entry reachable from the label
- [ ] The sprint report and portfolio print to A4 without clipped tables
- [ ] Each table on those pages exports to CSV with the same figures as shown
- [ ] The brand guide is Approved at a new version
